## Palette and type

| Colour | Hex | Role |
| --- | --- | --- |
| WSP red | `#FF372F` | Accent only, never long body text |
| Black | `#000000` | Dark backgrounds |
| Ink | `#1A1A1A` | Main text and diagram lines |
| White | `#FFFFFF` | Light backgrounds and reversed text |
| Light grey | `#F2F2F2` | Quiet panels |
| Mid grey | `#6B6B6B` | Secondary labels |

Font stack: **Arial, Helvetica, sans-serif**. GitHub Markdown controls its own body font; Mermaid and screenshot placeholders use this stack where supported. No custom web font or styling framework is needed.

## Logo care

- Keep clear space around the logo at least the **height of the "w"**.
- Use the red logo on light backgrounds and white on dark.
- **Never place the red logo on a red background.**
- Preserve aspect ratio. Specify height **or** width, not conflicting dimensions.
- Avoid decorative logo repetition. The lab name is GridScribe; WSP identifies the host.
