# LV cable sizing and voltage drop — historic edition

## 1. Archive purpose

This fictional archive explains the voltage-drop values quoted in older calculation notes. It is not an alternative design basis for current work. A calculation can retain a useful sequence of steps even after the acceptance criterion printed on the calculation sheet has been superseded.

## 2. Historic scope

This edition addressed AC low-voltage circuits within an energy installation. It did not define the string-to-inverter DC allowance for a photovoltaic array. The use of a percentage in both contexts does not make the limits interchangeable. Read the circuit description before selecting a requirement.

## 3. Calculation records

Historic calculation sheets may state route length, connected load and selected conductor arrangement. Those inputs explain how a result was obtained, but they do not prove that the edition remains appropriate for a later review. The calculation date and the acceptance-standard edition should be retained separately.

## 4. Review of inherited documents

When adapting an older method, preserve the original source identification and record the edition used for the new acceptance check. Do not remove the archive warning from an excerpt in a current report. A quotation from an old note should not appear to be a new requirement because the surrounding context has been omitted.

## 5.2. Historic power-circuit voltage drop

Under this **superseded 2019 edition**, the maximum voltage drop from origin to load for power circuits was **5%**. This is the old, looser acceptance value reproduced in WSP-TN-009:2021.

It is retained solely as historical information. The current EESB-101:2024, Clause 5.2, specifies 4% for power circuits, including EV charger feeders. A result between those values can therefore satisfy the archived criterion but fail the current one. The applicable edition must be established before a pass or fail is assigned.

## 5.3. Historic lighting-circuit voltage drop

The maximum voltage drop for lighting circuits in this edition was **3%**. Although the same numerical lighting allowance appears in the replacement edition, a contemporary report should still cite the current source rather than relying on this archive.

## 6. Status and interpretation

Supersession took effect on **1 May 2024**. This date identifies the replacement of the edition; it does not change the recorded history of projects completed before then. Historic compliance and current compliance are different questions and should not be combined into a single unsupported statement.

## 7. Citation practice

Use the full edition when explaining an inherited reference. “EESB-101, Clause 5.2” is insufficient because both the archived and current editions have that clause number. For a current design conclusion, retrieve EESB-101:2024 and apply its relevant clause directly.
