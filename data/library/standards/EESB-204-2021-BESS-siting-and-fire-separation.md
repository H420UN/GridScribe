## 1. Historic application

This archived edition records the fictional siting requirements that applied before replacement. It remains in the training library because earlier designs and technical notes refer to it. Its inclusion is not a statement that a designer may choose between editions according to which gives a more convenient layout.

## 2. Edition control

For a present-day assessment, consult EESB-204:2025 and its applicable amendment. This copy should be cited only to explain a historic decision or a change between editions. A reference to this document in a previous report does not transfer its former authority to a new project.

The replacement date is part of the document status, not a site commissioning date. A completed project can legitimately describe the edition used at the time while a new design must still establish its own current basis.

## 3. Layout record

The historic layout record identifies individual container positions, the compound outline and the site boundary. Container-to-container spacing and container-to-boundary clearance are distinct measurements. A statement that a compound has sufficient perimeter space does not establish the spacing between the containers inside it.

## 4.3. Historic container separation

Under this **superseded 2021 edition**, the minimum distance between BESS containers was **3 m**. This is the source of the value reproduced in some earlier project records and in WSP-TN-017:2022.

The value is retained here to support comparison with the replacement edition. It shall not be represented as the current standalone spacing requirement. A historical quotation should carry the edition and its superseded status whenever it appears in a contemporary review.

## 4.5. Historic boundary clearance

Under this **superseded 2021 edition**, BESS containers were to be at least **8 m from the site boundary**. This is not the current boundary requirement. The replacement edition changed the boundary distance as well as the arrangement for container separation.

## 5. Interpreting older records

A historic case study may be accurate about what was accepted when it was written. That accuracy does not make the earlier value suitable for a later design. Record the distinction between an authentic historic statement and a current acceptance criterion rather than describing every older document as factually false.

## 6. Retrieval and citation record

When this edition is retrieved alongside the 2025 document, the current document takes precedence for current requirements. Keep this archive available for the explanation of changes, but use the replacement clauses when completing a current compliance table. A citation containing only “EESB-204, Clause 4.3” is ambiguous because both editions contain that clause number.
