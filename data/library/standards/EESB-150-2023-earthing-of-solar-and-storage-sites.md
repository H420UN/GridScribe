# Earthing of solar and storage sites

| Title block | Detail |
|---|---|
| Document number | EESB-150 |
| Edition | 2023 |
| Status | Current |
| Date | 1 September 2023 |
| Scope | Earth electrodes, main earth rings and BESS container bonding on fictional solar and storage sites |

## 1. Application

This document provides a fictional framework for recording the earthing arrangement of a combined solar and storage installation. The assessment separates earth electrode performance from the physical provision of container bonds. A satisfactory resistance result does not, by itself, demonstrate that each required connection exists. Equally, a drawing showing two connections is not a measurement of electrode resistance.

## 2. Arrangement and identification

The earthing layout should identify the main earth ring, electrode locations and the equipment connected to it. Container identifiers should agree with the equipment schedule and inspection records. Labels used only on a test sheet should be explained if they differ from those on the layout, so that later reviewers can trace the result to the installation.

## 3. Design and construction records

The design record should distinguish the intended arrangement from the arrangement observed after construction. Changes to ring routing or equipment position should be reflected in the record drawings. A connection schedule can be used to list each container and its two connection points without treating several containers as one undifferentiated item.

## 4.2. Earth electrode resistance

The earth electrode resistance shall **not exceed 10 Ω**. The report should state the measured resistance, identify the tested electrode arrangement and cite this clause for the acceptance limit. The limit is a maximum, not a target value to be approached. A result below it should not be described as a failure simply because it differs from a preliminary estimate.

The resistance acceptance requirement belongs to this document. The fictional method for measuring the resistance is specified in EESB-190:2024, Clause 6.3. Keeping the limit and the method separately traceable avoids attaching a correct result to the wrong source.

## 4.4. BESS container bonding

Each BESS container shall be bonded to the main earth ring at **two separate points**. The evidence should identify both points for every container. A single shared entry describing the compound as bonded is insufficiently specific to demonstrate the two-point arrangement.

The two connections should be identifiable on the drawing and in the inspection record. The reviewer should be able to follow the evidence from the container identifier to both ring connections without inferring the second connection from a general note.

## 5. Inspection interface

The inspection record should describe accessible connection locations and distinguish completed observations from items awaiting inspection. This document does not prescribe a project-specific earth reading. An assumed or copied reading should not be presented as a completed test.

## 6. Reporting

Report electrode resistance and container bonding as separate conclusions. Reference the measured result for Clause 4.2 and the connection evidence for Clause 4.4. Supporting technical notes may describe a useful recording method, but they do not amend either requirement. Retain the document edition alongside the clause number in the design basis report.
