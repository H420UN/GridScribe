# Inspection, testing and commissioning

| Title block | Detail |
|---|---|
| Document number | EESB-190 |
| Edition | 2024 |
| Status | Current |
| Date | 1 July 2024 |
| Scope | Earth measurement method, LV insulation acceptance and BESS commissioning witness |

## 1. Application

This fictional standard addresses selected inspection and commissioning records for solar, storage and charging installations. It distinguishes a measured result from a design assumption and a pre-commissioning check from a witnessed commissioning event. The report should preserve those distinctions when summarising evidence.

## 2. Record identification

Test records should identify the installation, the equipment or circuit tested and the date of the observation. Circuit and container identifiers should agree with the project schedules. A summary containing only the lowest measured value should reference the relevant test set so that its scope can be understood.

## 3. Evidence boundaries

A completed test demonstrates the items included within its recorded scope. It does not automatically certify unrelated design decisions. For example, an acceptable earth reading is not evidence that the BESS spacing satisfies the current siting requirement.

## 4. Design and test interfaces

The review should distinguish the acceptance criterion from the measurement method. These can be specified in different documents. The design basis report should cite the source of the requirement and retain the test-sheet reference as the source of the observed value.

## 5. Review of results

Use the stated units and test conditions when comparing a result with its criterion. Do not copy a result into a different circuit category or omit the test voltage from an insulation summary. Where a sheet is a pre-commissioning record, retain that description rather than relabelling it as final operational acceptance.

## 6.3. Earth electrode measurement

Earth electrode resistance shall be measured by the **fall-of-potential method**. The record should identify the method alongside the result. The resistance acceptance limit is given in EESB-150:2023, Clause 4.2; this clause identifies how the measurement is to be obtained.

Separating the two references allows a reader to verify both the method and the acceptance decision without mistaking one for the other.

## 7. Inspection record

Inspection observations should identify the relevant equipment and distinguish observed provision from a design annotation. Use the same naming convention across the equipment schedule and inspection pack. This helps the reviewer relate a container connection record to the correct container.

## 8.1. LV insulation resistance

Insulation resistance for LV circuits shall be at least **1 MΩ at 500 V DC**. Record the test voltage with the measured resistance. A result expressed in megohms without the test condition is an incomplete basis for comparison with this clause.

## 9.2. BESS commissioning witness

BESS commissioning shall be **witnessed by the client's representative**. The commissioning record should identify the witness by project role and the event observed. A pre-commissioning electrical test sheet should not be presented as a substitute for the commissioning witness record.

## 10. Reporting

Keep test acceptance, layout compliance and commissioning status as separate conclusions. Where a document is deliberately limited to selected pre-commissioning results, describe that limit without inventing failed tests or implying that unlisted activities did not occur.
