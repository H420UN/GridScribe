# Grid connection and export limitation

| Title block | Detail |
|---|---|

## 1. Application

This fictional standard addresses the interface between an energy site and its grid connection. It is intended to keep the export-control function distinct from local equipment functions. A controller response described for the connection point should not be confused with the operation of an individual charger or a room ventilation system.

## 2. System definition

The design record should identify the connection point, the export-control boundary and the plant included within that boundary. Where solar generation and storage share a connection, the functional description should explain their participation in the scheme. A diagram should use the same equipment identifiers as the electrical single-line record.

## 3.3. Export-limitation response

The export limitation scheme shall **respond within 5 seconds**. The evidence should identify the initiating condition, the observed response and the equipment participating in the control chain. A response claim without a defined scheme boundary is difficult to interpret and should not be presented as a complete assessment.

The report should distinguish a design intention from an observed test result. A control description can establish how the scheme is intended to operate, while commissioning records provide evidence about the implemented arrangement. Neither should be silently substituted for the other.

## 3.5. Connection-point power factor

Power factor at the connection point shall be within the range from **0.95 lagging to 0.95 leading**. State the connection point when reporting the assessment. A figure for an individual inverter does not automatically describe the combined site at its grid interface.

The design narrative should make clear which operating arrangement is being discussed. This document does not assign a site-specific operating set point or export capacity.

## 4. Functional description

The functional description should connect the measurement, control decision and plant response in a readable sequence. Identify the interfaces between equipment packages so that an unallocated interface is not hidden by a statement that each package has its own controller.

When the plant arrangement changes, review the scheme description against the revised equipment list. Keep the record of intended operation separate from project correspondence about possible future expansion.

## 5. Evidence organisation

The review pack should retain the relevant diagrams, control description and test references under consistent revision identifiers. Where a result is repeated in a summary report, retain its source reference. The objective is traceability from a conclusion to evidence, not repetition of the same unreferenced statement in several documents.

## 6.1. Loss-of-mains protection

Loss-of-mains protection shall be provided for the grid connection. The design record should identify the protection function and its relationship to the site connection arrangement. This clause does not prescribe additional settings within this fictional extract.

## 7. Reporting

State the applicable clause for export response, power factor and loss-of-mains protection separately. A supporting technical note may explain the workflow, but it does not establish a different response time. Keep this grid-interface assessment distinct from cable voltage-drop and equipment-siting conclusions elsewhere in the report.
