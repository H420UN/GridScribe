# Fire detection in electrical rooms

| Title block | Detail |
|---|---|
| Document number | EESB-180 |
| Edition | 2022 |
| Status | Current |
| Date | 1 August 2022 |
| Scope | Automatic fire detection in inverter rooms and switch rooms, with remote alarm relay |

## 1. Application

This fictional document concerns fire detection within electrical rooms at energy sites. It addresses detection provision and the onward relay of alarms. It does not determine the separation between BESS containers or replace the separate gas-detection requirement for each BESS container in EESB-204:2025.

## 2. Room schedule

The design record should identify the rooms included in the detection arrangement. Room identifiers should agree with the site and building drawings. Where an inverter room and a switch room share a building, the schedule should still make the coverage of each room understandable.

An equipment package description should be linked to the room in which the equipment is installed. Merely listing a detector in a general equipment schedule does not explain which room it serves.

## 3. Functional description

The functional description should distinguish detection at the room from communication to the remote monitoring centre. These are related but separate parts of the arrangement. A report stating that an alarm can be displayed locally does not describe the onward relay required by Clause 4.3.

The evidence should identify the interfaces between the room system and the communication arrangement. Where separate packages are involved, keep the shared interface visible in the coordinated design record.

## 4.1. Automatic detection

**Automatic fire detection shall be provided in inverter rooms and switch rooms.** The room schedule and detection layout should show the provision for both room categories. The requirement concerns automatic detection, rather than a statement that personnel can report an observed event.

This extract does not select a detector technology or prescribe additional numerical settings. The report should not invent such details and attribute them to this clause.

## 4.3. Remote alarm relay

Alarms shall be relayed to a **24/7 remote monitoring centre**. The design record should identify the relay arrangement and the receiving function. The presence of a local display should not be presented as evidence that the remote relay has been implemented.

The narrative should make clear that “24/7” describes the receiving monitoring provision. It is not a response-time value and should not be converted into a timing criterion.

## 5. Commissioning interface

The commissioning record should distinguish observations at the initiating room system from observations at the receiving centre. Use matching room and alarm identifiers so that a result can be followed through the chain. Retain the source of each observation rather than repeating an unreferenced summary in several places.

## 6. Reporting

Record room detection and remote relay as separate conclusions supported by the relevant evidence. A limitation in the scope of a particular test sheet should not automatically be described as a failed installation. Identify what the sheet demonstrates and where the remaining evidence is held.

## 7. Related requirements

BESS gas detection belongs to EESB-204:2025, Clause 5.1. A room-detection statement should not be substituted for that container-specific provision, even if both systems are discussed in a common project review.
