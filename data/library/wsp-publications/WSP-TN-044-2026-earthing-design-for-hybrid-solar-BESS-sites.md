# Earthing design for hybrid solar–BESS sites

| Title block | Detail |
|---|---|
| Document number | WSP-TN-044 |
| Edition | 2026 |

| Author role | Earthing Design Specialist |
| Scope | Twin container bonds, post-construction earth testing and traceable evidence |

## 1. Purpose

Hybrid sites bring together several equipment packages and their associated connection records. The main documentation risk is that each package describes its own provision without showing how it connects to the common site arrangement. This note recommends a simple way to keep the ring, the container connections and the test result traceable.

It is a fictional supporting note, not a source of additional earthing acceptance limits.

## 2. Twin bonding

Provide **twin bonding for each BESS container in accordance with EESB-150:2023, Clause 4.4**: two separate points to the main earth ring. Show both connection points against the individual container identifier.

A compound-level statement that “earthing is provided” can conceal the information needed for a container-by-container review. The drawing and connection schedule should describe the same arrangement, using the same container names.

## 3. Post-construction testing

Carry out an **earth test after construction** so that the project record includes evidence from the installed arrangement rather than only a design estimate. The fictional measurement method is the fall-of-potential method in EESB-190:2024, Clause 6.3.

Use EESB-150:2023, Clause 4.2, for the maximum electrode resistance of 10 Ω. The test method and the acceptance limit come from different clauses, and both should be identifiable in the review record.

## 4. Keep two conclusions separate

The electrode result and the count of container bonds answer different questions. A low electrode resistance does not prove that the second bond exists. A drawing with two connection symbols does not demonstrate a measured resistance.

The review summary should therefore include a resistance statement and a bonding statement. Each should refer to the evidence appropriate to that question, rather than relying on a single broad claim that the earthing system is satisfactory.

## 5. Recording the installed arrangement

During close-out, carry equipment identifiers from the design into the inspection and test records. If a container has been relocated, update the connection description so the reviewer can follow both bonds to the intended ring.

Record drawings should distinguish the installed arrangement from an option discussed earlier in the design. This is especially helpful where the compound layout has changed without changing the container count.

## 6. Commissioning interface

Electrical pre-commissioning results are not a substitute for the BESS commissioning witness record under EESB-190:2024, Clause 9.2. Keep the purpose of each record visible. A limited test summary should not be read as a claim about every commissioning activity.

## 7. Recommended report approach

Cite the current standard and relevant clause for each requirement, then identify the project record supplying the design or measured value. This note can explain the recording approach but cannot override the standard. Reviewers should avoid turning an evidence-format preference into an invented numerical requirement.
